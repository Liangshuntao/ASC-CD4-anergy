# Proteomic result replay

This workflow starts from the historically processed protein/GSVA checkpoint,
not a new stochastic MinProb imputation. The original raw script contains an
expression-matrix assignment error and did not record the imputation seed; it
must not be run verbatim or silently repaired and claimed to reproduce the paper.

Export the whitelisted saved objects from the original workspace using
export_proteomics_checkpoint.R, then run:

```
Rscript analysis/proteomics/run_proteomics_replay.R --checkpoint /path/proteomics_published_state.rds --out /path/new_output --stage model
Rscript analysis/proteomics/run_proteomics_replay.R --checkpoint /path/proteomics_published_state.rds --out /path/new_output --stage all
```

The default stromal pathway selection is supplied under metadata/. It records
the actual selected pathways used by the historical figure code; it is not a
new data-driven selection. --asc-pathways may specify that original table at
another location, not an alternative scientific selection.

Stages: original protein/pathway limma models; compartment PCA; ASC pathway plots;
ASC candidate-module heatmap; CD4 pathway/proliferation plots; supplementary
differential-protein heatmaps and volcano plots. Inputs include
historical imputed expression, six-sample compartment metadata, protein annotation,
gene-level expression and original pathway-score matrices. Models retain the
original factors, contrasts, BH correction and thresholds. No new imputation,
gene-set download, GO/KEGG run or GSVA recalculation is performed by this replay.
No package is installed. Dependencies: limma, dplyr, tibble, ggplot2, pheatmap.
Interface repairs are explicitly limited to UTF-8-BOM input decoding and using
as.matrix() on an already-matrix checkpoint so its row names are retained. Neither
repair changes numeric entries, contrasts or cutoffs. The replay models reproduced
four historical result tables exactly (all seven numeric fields, zero maximum
absolute difference). Full plot-stage execution passed; pixel-identical matching
to manuscript composites is not claimed.

Figure 9D is a manual cell-cycle schematic and is not generated by the R workflow.
Other panels retain original plotting calculations; manuscript typography and
composite arrangement may have been edited separately. Original unprocessed input
and workspace remain outside this code repository. Their public access route is
a separate data-availability requirement, not satisfied by this code archive.
