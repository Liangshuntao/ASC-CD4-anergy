# Proteomic result replay

This workflow uses saved imputed protein-expression and pathway-score matrices
to generate the proteomic analyses and figures. It does not repeat imputation
or pathway scoring.

Export the required saved objects from the original workspace using
export_proteomics_checkpoint.R, then run:

```
Rscript analysis/proteomics/run_proteomics_replay.R --checkpoint /path/proteomics_published_state.rds --out /path/new_output --stage model
Rscript analysis/proteomics/run_proteomics_replay.R --checkpoint /path/proteomics_published_state.rds --out /path/new_output --stage all
```

The stromal pathways used in the figures are listed under metadata/.
Use --asc-pathways to supply this table from another location.

Stages: original protein/pathway limma models; compartment PCA; ASC pathway plots;
ASC candidate-module heatmap; CD4 pathway/proliferation plots; supplementary
differential-protein heatmaps and volcano plots. Inputs include
historical imputed expression, six-sample compartment metadata, protein annotation,
gene-level expression and original pathway-score matrices. Models retain the
original factors, contrasts, BH correction and thresholds. No new imputation,
gene-set download, GO/KEGG run or GSVA recalculation is performed by this replay.
No package is installed. Dependencies: limma, dplyr, tibble, ggplot2, pheatmap.

Figure 9D is a manual cell-cycle schematic and is not generated by the R workflow.
Input availability is described in [DATA_ACCESS.md](../../DATA_ACCESS.md).
